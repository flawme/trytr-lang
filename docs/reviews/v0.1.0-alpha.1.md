# Adversarial release review: v0.1.0-alpha.1

This review targets the first alpha's document, streaming, checker, optional
browser-export, and distribution boundaries. It combines code inspection,
purposeful failure cases, sanitizer runs, and clean-runner archive validation.
It is a scoped release review, not a claim that every possible defect is absent.

## Findings and fixes

| Finding | Impact | Resolution |
| --- | --- | --- |
| Algebra CLI skipped every row starting with an align-environment prefix. | A malformed wrapper could hide an unchecked equation while other rows produced an overall verified result. | Only exact standalone `align` / `align*` wrappers are ignored; inline claims and malformed wrappers produce explicit unchecked rows. MCP regression tests cover both paths. |
| PDF export waited without a deadline and could block on a descendant retaining stderr. | A failed or stuck browser could hang the CLI. | A monotonic 30-second deadline bounds polling and log draining; a dedicated process group is killed and the child reaped before returning. Tests cover hangs, inherited pipes, and continuous stderr output. |
| Version/package/MCP metadata advertised stable `0.1.0` for an alpha. | Users could mistake the candidate for a stable release. | The public header defines `0.1.0-alpha.1`; CLI, CPack assets, and MCP metadata agree. CMake's numeric package version is explicitly documented. |
| The optional web demo omitted `build/release/trytr` from executable discovery. | A release-only source build could not run the demo. | Release build discovery is included; web validation tests now run in CTest against the configured executable, with the online service mocked. |
| Licensing and public onboarding were incomplete. | The source/SDK lacked declared distribution terms and a complete entry point. | Canonical Apache 2.0 LICENSE, project NOTICE, expanded README, release notes, and install checks were added. |

## Adversarial cases

- Malformed source, UTF-8 splits, every two-chunk boundary in a mixed document,
  attempted wrapper escapes, unknown parameters, duplicate IDs, and stale
  revisions must never replace the last valid stream snapshot.
- Multi-parameter batches with an invalid value or geometry failure remain
  atomic. Retained snapshots preserve old math/plot data, survive destruction
  of the stream, and enforce retryable retention limits.
- `x/x=1`, `0/x=0`, `(x/x)^0=1`, nested fractions, and reciprocal powers retain
  their divisor obligations. Identically zero divisors remain invalid, including
  inside a term multiplied by zero. False identities, unsupported functions,
  coefficient overflow, and source/degree/nesting/work limits are separate cases.
- Hostile HTML characters remain escaped. README source examples and their
  parameter overrides are compiled during tests; documentation links and
  version/license metadata are checked offline.
- Browser failure tests enforce a 4 KiB diagnostic cap and private stdout.
  Hanging children, lingering descendants, and continuous output must return
  within the shortened test deadline. Normal PDF integration remains covered.
- SDK checks install into a path with spaces, relocate it, and compile a fresh
  consumer against public headers and CMake targets. Installed licenses must
  exactly match the source. CI also extracts the Git source archive and rebuilds
  and tests it independently of the original checkout/build tree.

## History and distribution review

Before release edits, 360 unique file blobs (3,491,372 bytes) reachable from all
local Git refs were scanned for common provider-token, private-key, and quoted
credential-assignment patterns. No matches were found. Filename and attribution
review found no bundled local configuration, third-party library source,
browser, font, or TeX distribution. This pattern scan does not prove the absence
of every possible secret. The final release assets are checked again before
publication; local settings and build logs are not shipped.

The release workflow retains archives and checksums only after tests succeed.
The published tag is pinned to that reviewed/tested commit; CI evidence and
asset checksums are linked from the GitHub release. Native MathML appearance
still depends on the host browser/fonts. Broad manual cross-browser typography
QA and non-Linux platform qualification remain outside this alpha's claims.
