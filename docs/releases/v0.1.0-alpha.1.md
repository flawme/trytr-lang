# Trytr v0.1.0-alpha.1

The first public alpha of Trytr, a compact C document language for AI chat and
scientific explanations. Licensed under Apache 2.0.

## Included

- Headings, paragraphs, inline/display mathematics, bounded integer parameters,
  geometric shapes, groups, expression-based paths, and formula plots.
- Native HTML paragraphs and browser MathML in reading order; scalable vector
  canvases for plots and drawings. Separate text, SVG, MathML, and optional PDF
  output paths are available.
- Explicit streaming append frames with atomic publication, revision conflicts,
  retained snapshots, and atomic parameter changes that work after finish.
- Exact polynomial and rational identity review through `trytr-proof` and MCP.
  Rational identities preserve original nonzero divisor conditions. Narrow
  Peano-equality and polynomial-limit certificates remain separate checkers.
- An installable static C SDK, public headers, examples, and relocatable CMake
  targets: `trytr::core`, `trytr::math`, and `trytr::proof`.

## Downloads and verification

- `trytr-0.1.0-alpha.1-Linux-x86_64.tar.gz`: CLI tools and SDK, built on Ubuntu
  24.04 x86_64 with GCC. Other distributions should build from source when the
  binary's system-library requirements are unavailable.
- `trytr-0.1.0-alpha.1-source.tar.gz`: source from the release commit, without Git
  metadata, local configuration, or build products.
- `SHA256SUMS`: checksums for both archives. Run `sha256sum -c SHA256SUMS` after
  downloading them into one directory.

The CI workflow tests GCC and Clang in debug/sanitized and release builds,
checks SDK installation/relocation, and builds/tests a fresh source-archive
extraction before retaining release assets. The GitHub release links the
specific passing run. These hashes identify the uploaded files; they are not
cryptographic signatures by the maintainer.

## Requirements and limits

Source builds need CMake 3.20+, Ninja, and GCC 13+ or Clang 18+. Python 3.10+
runs integration tests and the optional source-tree MCP adapter. Native HTML
output needs a browser with MathML support, without TeX or JavaScript. PDF
export additionally needs a locally installed compatible Chromium-family
browser; its process has a 30-second deadline and bounded diagnostics.
The prebuilt Linux CLI expects `/opt/google/chrome/chrome` for PDF export.
Source builds can select another installation with CMake's
`-DTRYTR_CHROMIUM_EXECUTABLE=/absolute/path/to/browser` option.

This is an **alpha**, with no stable syntax or ABI guarantee. CMake uses the
numeric package version `0.1.0`; runtime/release metadata includes `alpha.1`.
Streaming reparses full candidates and is single-threaded. The document source
limit is 1 MiB, each document arena is 4 MiB, and a stream retains up to eight
snapshot objects. Check the documented ownership rules before embedding.

Math layout is a notation/typesetting feature, not proof checking. The checker
does not verify arbitrary functions, inequalities, assumptions, or prose, and
conditional results do not count as unconditional proofs. Symbols in algebra
review are commutative scalar variables; parentheses after a scalar denote
multiplication. Font shaping, pagination, complete LaTeX coverage, typed vector
expressions, tables, units, and dependency-based incremental updates are future
work. SVG/PDF math preserves notation source rather than native typesetting.
